# Results figures

Generated by `scripts/make_results_figures.py` (run: `.venv/bin/python scripts/make_results_figures.py`).
Every number is recomputed from the raw run files and asserted against the
values in [TASK2_WEB_V3_RESULTS.md](../TASK2_WEB_V3_RESULTS.md) and Table 1, so
figures and tables cannot disagree. Use the **PDF** files in the paper (vector);
the PNG files are previews.

Style: Elsevier artwork sizes (final width 90 / 140 / 190 mm), Liberation Sans
(Arial-metric) 6.5–8.5 pt at final size, white background. Colours are fixed
across all figures: **grey `#8c8b85` = Browser Use alone / untrained approach**,
**blue `#2a78d6` = Browser Use + Ours / our trained heads**; red `#e34948` =
hurt pairs only. Palettes checked with the colour validator (CVD and contrast).

## Facts shown in the figures (for the text)
- Completion: Browser Use 72.6 % → + Ours 85.7 % (all 84 pairs, p = 0.007);
  development 70.0 → 87.5 (p = 0.039); held-out 75.0 → 84.1 (p = 0.219).
- Pairs: helped 13, hurt 2, same 69; rescue 57 % (13/23), harm 3 % (2/61).
- Where recovery opened (31 pairs): Browser Use 45 %, Ours 84 %; helped 12, hurt 0.
  Where the detector stayed silent (53 pairs): 89 % vs 87 %; helped 1, hurt 2.
- Cost: mean episode 220 s vs 175 s; steps on both-completed pairs 3.08 vs 3.32.
- Task 1: same Qwen2.5-VL-7B prompted MCC 0.00 (Browser Use / Agent S2 style) or
