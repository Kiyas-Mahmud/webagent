# Results figures v2: WebFARM on two agents

Generated by `scripts/make_results_figures_v2.py`
(run: `.venv/bin/python scripts/make_results_figures_v2.py`, or name single figures, e.g. `R03 R04`).
Each figure is saved three times: **PDF** (vector, use in the paper), **SVG**
(vector with editable text) and **PNG** (300 dpi preview).

Every number is recomputed from the raw run files (web-v3, web-v4-seeact,
web-v5-seeact-ours, Task 1 pilot records) and asserted against the values in
[Results_Comparison_Handout.pdf](../Results_Comparison_Handout.pdf) Tables 2
and 6–20, so figures and tables cannot disagree. The v1 figures in
[../figures/](../figures/) (Browser Use only) are kept unchanged.

## Visual concept (same in every figure)

| Element | Meaning |
|---|---|
| Grey | agent alone (Browser Use or SeeAct without WebFARM) |
| Blue | agent + WebFARM |
| Red | harm only (a pair WebFARM lost, or a step P1 judged failed) |
| Panel / group label | which agent, when the agents are shown separately |
| Solid line, circle | Browser Use, when both agents share one axis |
| Dashed line, square | SeeAct, when both agents share one axis |
| Hatched bar | SeeAct, in the one bar chart where both WebFARM variants share an axis (A3) |

Text is near-black only, 7–8.5 pt at final size (10 pt for the confusion-matrix
counts), Liberation Sans (Arial-metric). Widths follow Elsevier artwork sizes.
